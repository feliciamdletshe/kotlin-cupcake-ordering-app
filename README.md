# kotlin-cupcake-ordering-app

# Overview
A mobile application developed using Kotlin and Jetpack Compose that allows users to place cupcake orders through a multi-screen ordering process.

# Features
Select cupcake quantity
Choose cupcake flavour
Select pickup date
View order summary
Navigation between screens using Jetpack Compose Navigation
Order cancellation and reset functionality

# Technologies Used
Kotlin
Jetpack Compose
Android Studio

# Screens
Start Order Screen
Flavour Selection Screen
Pickup Date Screen
Order Summary Screen
